## ðŸ”§ Orchestrator API

### OASISOrchestrator Class

#### Initialization

```python
from oasis_orchestrator import OASISOrchestrator

# Initialize with config file
orchestrator = OASISOrchestrator("oasis_config.json")

# Initialize with custom config
config = {
    "hugging_face": {
        "token": "hf_your_token",
        "endpoints": {...}
    }
}
orchestrator = OASISOrchestrator(config)
```

#### Core Methods

##### `make_request(url, data=None, method="GET", headers=None)`

Low-level HTTP request method using pure urllib.

**Parameters:**
- `url` (str): Target URL
- `data` (bytes, optional): Request payload
- `method` (str): HTTP method ("GET", "POST", "PUT", "DELETE")
- `headers` (dict, optional): HTTP headers

**Returns:** Response text or None on error

**Example:**
```python
# GET request
response = orchestrator.make_request("https://api.example.com/data")

# POST request with JSON
import json
payload = json.dumps({"text": "Hello world"}).encode('utf-8')
response = orchestrator.make_request(
    "https://api.example.com/process",
    data=payload,
    method="POST",
    headers={"Content-Type": "application/json"}
)
```

##### `analyze_sentiment(text)`

Analyze sentiment of input text.

**Parameters:**
- `text` (str): Text to analyze

**Returns:** Sentiment analysis result (str/dict)

**Example:**
```python
result = orchestrator.analyze_sentiment("I love this product!")
print(f"Sentiment: {result}")
# Output: Sentiment: {"label": "POSITIVE", "score": 0.9998}
```

##### `translate_text(text, target_language="english", source_language="auto")`

Translate text between languages.

**Parameters:**
- `text` (str): Text to translate
- `target_language` (str): Target language name
- `source_language` (str): Source language ("auto" for detection)

**Returns:** Translated text (str)

**Example:**
```python
translation = orchestrator.translate_text("Hola mundo", "english")
print(f"Translation: {translation}")
# Output: Translation: Hello world
```

##### `summarize_text(text, max_length=150)`

Generate text summary.

**Parameters:**
- `text` (str): Text to summarize
- `max_length` (int): Maximum summary length

**Returns:** Summary text (str)

**Example:**
```python
long_text = "Long article content here..."
summary = orchestrator.summarize_text(long_text, max_length=100)
print(f"Summary: {summary}")
```

##### `generate_text(prompt, max_length=100)`

Generate text based on prompt.

**Parameters:**
- `prompt` (str): Text prompt
- `max_length` (int): Maximum generated length

**Returns:** Generated text (str)

**Example:**
```python
generated = orchestrator.generate_text("The future of AI is", max_length=50)
print(f"Generated: {generated}")
```

##### `analyze_emotion(text)`

Detect emotions in text.

**Parameters:**
- `text` (str): Text to analyze

**Returns:** Emotion analysis result (str/dict)

**Example:**
```python
emotion = orchestrator.analyze_emotion("I'm so excited about this!")
print(f"Emotion: {emotion}")
# Output: Emotion: {"label": "joy", "score": 0.95}
```

##### `run_interactive()`

Start interactive CLI mode.

**Example:**
```python
orchestrator.run_interactive()
# Starts interactive command-line interface
```

## ðŸŒ HuggingFace Spaces API

### Endpoints

The HF Spaces application exposes these endpoints:

#### POST `/predict_sentiment`
```json
{
  "text": "I love this product!"
}
```

#### POST `/predict_translate`

```json
  "target_language": "spanish"
}
```

#### POST `/predict_summarize`
```json
{
  "text": "Long text content...",
  "max_length": 150
}
```

#### POST `/predict_generate`
```json
{
  "prompt": "The future of AI is",
  "max_length": 100
}
```

#### POST `/predict_emotion`
```json
{
  "text": "I'm feeling great today!"
}
```

### Response Format

All endpoints return JSON responses:

```json
{
  "result": "Processed output here",
  "status": "success",
  "processing_time": 0.245
}
```

Error responses:
```json
{
  "error": "Error description",
  "status": "error",
  "code": 400
}
```

| Code | Description | Solution |
|------|-------------|----------|

## ðŸ“Š Performance Optimization

### Best Practices

1. **Batch Requests**: Group multiple operations when possible
2. **Caching**: Cache frequent results locally
3. **Timeout Management**: Set appropriate timeouts for mobile
4. **Error Recovery**: Implement exponential backoff
5. **Resource Management**: Monitor memory and battery usage

### Example Batch Processing

```python
texts = ["Text 1", "Text 2", "Text 3"]
results = []

for text in texts:
    try:
        result = orchestrator.analyze_sentiment(text)
        results.append(result)
    except Exception as e:
        print(f"Failed for '{text}': {e}")
        results.append(None)

print(f"Processed {len([r for r in results if r])} out of {len(texts)}")
```
