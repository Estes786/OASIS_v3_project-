## ðŸ“‹ **How to Contribute**

### 1. **Bug Reports**
- Use GitHub Issues with the "bug" label
- Include steps to reproduce
- Specify environment details (OS, Python version, etc.)

### 2. **Feature Requests**
- Use GitHub Issues with the "enhancement" label
- Describe the use case and expected behavior
- Consider the ultra-lightweight philosophy

### 3. **Code Contributions**
- Fork the repository
- Create a feature branch: `git checkout -b feature/amazing-feature`
- Make your changes following our guidelines
- Add tests if applicable
- Commit with clear messages
- Push to your fork
- Create a Pull Request

## ðŸ“ **Development Guidelines**

### Code Style
- Follow PEP 8 for Python code
- Use type hints where appropriate
- Keep functions small and focused
- Write clear, descriptive variable names

### Architecture Principles
- **NO HEAVY DEPENDENCIES**: Avoid numpy, pandas, torch, transformers
- **API-First**: Use Hugging Face APIs instead of local models
- **Ultra-Lightweight**: Keep total footprint under 5MB
- **Mobile-Friendly**: Ensure compatibility with Termux

### Testing
```bash

python -m pytest tests/

# Check code quality
black .
flake8 .
```
