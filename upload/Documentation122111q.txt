## ðŸš€ Quick Start

### 1. Setup (One-time)
```bash
# Make executable and run setup
chmod +x setup.sh
./setup.sh
```

### 2. Configure URLs
Edit `oasis_config.json` with your HuggingFace Spaces URLs:
```json
{
  "orchestrator_url": "https://your-orchestrator-space.hf.space",
  "api_processor_url": "https://your-api-processor-space.hf.space",
  "ui_interface_url": "https://your-ui-interface-space.hf.space"
}
```

### 3. Start Using
```bash
# Interactive mode (recommended)
./oasis_client.py

# Or with command line arguments
./oasis_client.py --sentiment "I love this product!"
```

## ðŸ”§ Configuration

### Basic Configuration (`oasis_config.json`)
```json
{
  "orchestrator_url": "https://your-orchestrator-space.hf.space",
  "api_processor_url": "https://your-api-processor-space.hf.space",
  "ui_interface_url": "https://your-ui-interface-space.hf.space",

    "auto_register": true,

    "log_level": "INFO"
  }
}
```

```bash
export OASIS_DEBUG=true
```
