## 🚀 **FUNCTIONAL ENTRY POINTS**

### **Web Application** (`index.html`)
**Primary Interface** - Full-featured business dashboard
- **Path**: `/` or `/index.html`
- **Features**: All business functions, mobile-optimized
- **Parameters**: None (self-contained)

### **Gradio Interface** (`app.py`)
**Deployment Interface** - Hugging Face Spaces integration
- **Path**: Gradio web interface on port 7860
- **Features**: App launcher, demo tools, setup guides
- **Parameters**: Optional HF token for private models

### **API Endpoints** (RESTful Table API)
**Data Management** - Backend data operations
- **Base URL**: `tables/`
- **Endpoints**: 
  - `GET/POST tables/clients` - Client management
  - `GET/POST tables/revenue` - Revenue tracking
  - `GET/POST tables/api_calls` - API usage logs
  - `GET/POST tables/workflows` - Automation workflows
