#### Step 3: Configuration
```bash

    'api_endpoint': 'https://api-inference.huggingface.co',
    'default_model': 'gpt2',
    'max_requests_per_minute': 60,
    'enable_logging': True
}
with open('config/settings.json', 'w') as f:
    json.dump(config, f, indent=2)
"
```

## ðŸ› ï¸ Troubleshooting

### Common Issues

#### "Module not found" Error
```bash
# Check Python path
python3 -c "import sys; print('\n'.join(sys.path))"

# Install missing dependencies
pip install --no-cache-dir requests python-dotenv flask
```

#### "Connection refused" to Hugging Face API
```bash
# Check internet connection
ping 8.8.8.8

# Verify API key
grep HUGGINGFACE_API_KEY config/.env

# Test API directly
curl -H "Authorization: Bearer YOUR_API_KEY" \
     https://api-inference.huggingface.co/models/gpt2
```

#### High memory usage
```bash
# Monitor memory
python3 monitoring_dashboard.py
> system

# Optimize settings
# Edit config/settings.json:
# - Reduce cache size
# - Lower max_requests_per_minute
# - Enable request compression
```

#### API gateway not starting
```bash
# Check port availability
netstat -tlnp | grep 8000

# Try different port
python3 api_gateway.py --port 8080

# Check logs
tail -f logs/api_gateway.log
```

### Debug Mode
```bash
# Enable verbose logging
export DEBUG=true

# Start services with debug output
python3 api_gateway.py --debug
python3 oasis_hf_controller.py --verbose
```

### Log Analysis
```bash
# View recent errors
grep -i error logs/*.log | tail -20

# Monitor real-time logs
tail -f logs/system.log

# Clear old logs
find logs/ -name "*.log" -mtime +7 -delete
```
